Automated Banking System using Agile

1. Abstract 

An Automated Banking System is a software application that provides customers with online banking services such as account creation, balance inquiry, fund transfer, and transaction history. Traditional banking systems depend heavily on manual processes, which can be time-consuming, error-prone, and inconvenient for customers. With the increasing demand for digital banking, there is a need for an automated system that offers fast, secure, and reliable banking services.

This project focuses on developing an Automated Banking System using Agile methodology. The system allows users to create bank accounts, log in securely, check account balances, transfer funds, and view transaction details. The system also enables bank administrators to manage customer accounts and monitor transactions. By automating routine banking operations, the system reduces human effort and improves accuracy.
