Online E-Commerce Website using Agile

1. Abstract 

An Online E-Commerce Website is a digital platform that allows customers to buy and sell products over the internet. With the rapid growth of technology and internet usage, online shopping has become one of the most popular ways to purchase goods. Traditional shopping methods require customers to visit physical stores, which can be time-consuming and inconvenient. An e-commerce system helps overcome these limitations by providing a simple, fast, and accessible shopping experience.

This project focuses on developing an Online E-Commerce Website using Agile methodology. The proposed system allows users to register, browse products, add items to a shopping cart, place orders, and make secure online payments. The system also provides features such as order tracking and order history. From the admin side, the system helps manage products, prices, stock, and customer orders efficiently.

2. Introduction
2.1 Introduction

An e-commerce website enables businesses to sell products online and customers to shop from anywhere at any time.

2.2 Problem Identification

Physical stores have limited working hours and reach. Manual billing and inventory handling can lead to errors and inefficiency.

2.3 Need of the Project

There is a need for an automated system that allows easy product browsing, ordering, and secure online payment.

2.4 Project Scheduling

The project is developed using Agile methodology and divided into sprints such as requirement gathering, development, testing, and review.

To provide an online shopping platform

To improve customer experience
