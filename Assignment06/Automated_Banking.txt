Automated Banking Website


1. Introduction

This document describes the manual testing performed on the Automated Banking Website. Manual testing is conducted to verify that the banking application functions correctly according to the given requirements. The Automated Banking Website provides users with online banking services such as account login, balance inquiry, fund transfer, and transaction history.

Manual testing ensures that all banking operations are performed accurately and securely, and that the system handles invalid inputs properly. The goal of this test report is to validate the reliability and usability of the banking system.


2. Objective of Testing

The objectives of manual testing are:

To verify correct working of banking functionalities
To ensure secure login and transactions
To validate balance updates after transactions
To identify defects in the system
To ensure user-friendly operation

3. Scope of Testing

The scope of testing includes:

User Login
Balance Inquiry
Fund Transfer
Transaction History
Logout Functionality
Manual functional testing is performed on all these modules.

4. Test Environment

5. Test Strategy

Black Box Testing approach is used
Functional testing is performed
