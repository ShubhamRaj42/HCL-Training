Online E-Commerce Website


1. Introduction

This document describes the manual testing performed on the Online E-Commerce Website. Manual testing is conducted to verify that the system works according to the specified requirements and provides correct output for valid inputs while handling invalid inputs properly.

The Online E-Commerce Website allows users to register, log in, browse products, add items to a shopping cart, place orders, and make online payments. Manual testing ensures that all these functionalities work smoothly and provide a good user experience.

2. Objective of Testing

The objectives of manual testing are:
To verify the correctness of e-commerce functionalities
To ensure secure and accurate order processing
To validate user input and error handling
To identify defects in the system
To improve system reliability and usability
