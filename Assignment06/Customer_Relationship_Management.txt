Customer Relationship Management (CRM) System

1. Introduction

This document describes the manual testing performed on the Customer Relationship Management (CRM) system. Manual testing is carried out to verify that the CRM application functions according to the specified requirements and provides correct output for valid inputs while handling invalid inputs properly.

The CRM system includes features such as customer registration, login, customer data management, interaction tracking, and complaint management. Manual testing helps ensure that all modules of the system work correctly and meet user expectations.

2. Objective of Testing

The main objectives of manual testing are:

To verify all CRM functionalities work as expected
To identify defects or errors in the system
To ensure data accuracy and security
To validate user input handling
To improve overall system quality

3. Scope of Testing

The scope of testing includes the following modules:

User Login
Customer Registration
Customer Data Management
Complaint Management
Logout Functionality
Testing is performed using manual test cases without using automation tools.

4. Test Environment

Operating System: Windows
Application Type: Web / Desktop Application
Backend: Java
Database: MySQL
Testing Type: Manual Testing

5. Test Strategy

Black Box Testing approach is used
Functional testing is performed
Both valid and invalid inputs are tested
Actual results are compared with expected results
